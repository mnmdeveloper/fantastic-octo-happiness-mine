# CutVPN Prank UI

XP/Vista-inspired prank installer content for the CutVPN demo.

Included themes:
- Personal offers / Workrave gag
- Cockroach on Desktop gag
- Goose sale gag with a single BUY button
- Cheburetnet shitting wizard
- GENSUHA / VYAZANKA / OSEMENIT.Bimbim nonsense
- Fake framework update and security-update messages
- Random-error message pool

The prank content is intentionally presented as part of CutVPN and does not masquerade as Windows system dialogs.
